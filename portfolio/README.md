# Portfolio — Anas Semghouni

Portfolio personnel construit avec React, TypeScript, Vite, React Router et Tailwind CSS.

## Développement

```sh
npm install
npm run dev
```

## Organisation du code

```text
src/
├── components/  # En-tête, pied de page et composants partagés
├── data/        # Navigation, compétences et expériences
├── hooks/       # Hooks React réutilisables
├── pages/       # Une page par route
├── styles/      # Styles globaux et styles du portfolio
├── App.tsx      # Déclaration des routes
└── main.tsx     # Point d’entrée React et BrowserRouter
```
